# Legendary Rooster

Game bắn máy bay theo phong cách arcade, xây dựng bằng HTML5 Canvas, JavaScript và CSS. Người chơi điều khiển một chiến kê “rooster” mạnh mẽ, bắn trứng phá hủy máy bay địch, tích lũy vàng, nâng cấp vũ khí và vượt qua nhiều màn chơi khác nhau.

## Tính năng chính

- 3 màn chơi với độ khó tăng dần
- Hệ thống thu thập vàng và xu hồi sinh
- Cửa hàng nâng cấp: vũ khí, khiên, động cơ, xu hồi sinh
- Màn boss ở giai đoạn cuối
- Điều khiển bằng bàn phím và cảm ứng di động
- Lưu tiến độ bằng localStorage

## Cách chạy dự án

1. Mở terminal trong thư mục dự án
2. Chạy lệnh:

```bash
python -m http.server 8000
```

3. Mở trình duyệt và truy cập:

```text
http://localhost:8000/
```

## Điều khiển

- Di chuyển: Left/Right hoặc A/D
- Bắn: Space
- Tạm dừng: P hoặc Esc
- Trên điện thoại: các nút điều hướng và bắn xuất hiện ở dưới màn hình

## Mục tiêu chơi

- Tiêu diệt máy bay địch để kiếm vàng
- Nâng cấp vũ khí và bảo vệ
- Mở khóa màn mới
- Hoàn thành mục tiêu từng cấp độ và đánh bại boss

## Ghi chú

Dự án này là phiên bản trò chơi đơn giản, phù hợp để học tập và phát triển thêm các tính năng như âm thanh, hiệu ứng, menu, leaderboard và nhiều level hơn.
